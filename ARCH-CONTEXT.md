# 🗺️ Архитектурный контекст платформы: LogiKids (v2.2.0)

Этот файл — единственный источник правды (Single Source of Truth).
Передавайте его ИИ-помощникам (Главный инженер / DeepSeek) при старте любой сессии.

## 🎯 Описание проекта
Коммерческая EdTech B2C/B2B веб-платформа интерактивных развивающих и логических игр для детей. Продукт полностью интернационализируемый, имеет нейтральный игровой интерфейс без привязки к конкретным именам.

## 🚀 Архитектурные принципы и Стек
1. **Стек:** Vite, чистый TypeScript, HTML5, CSS. Без тяжелых UI-фреймворков (Vue/React) для максимальной производительности на детских планшетах и смартфонах.
2. **Строгий TypeScript:** Запрет на использование `any`. Строгая типизация через интерфейсы.
3. **Монолитное ядро (Shared Core):** Таймеры, общая бизнес-логика и менеджеры стейта лежат в `src/core/`.
4. **Изолированные игры:** Каждая игра наследуется от `BaseGame` и инкапсулирует свою логику.
5. **Коммерческий Стейт:** Все локальные сохранения рекордов в браузере используют префикс `logikids_`.

## 📂 Структура папок
* `src/core/` — Глобальные менеджеры (Timer.ts, StateManager.ts).
* `src/games/` — Каталог игровых модулей.
* `src/components/` — Переиспользуемые UI-компоненты платформы.

## 🤖 Правила для Кодера (DeepSeek)
* Никаких хардкод-имен в UI (только нейтральные заголовки "Игрок", "Рекорд", "Уровень").
* Дизайн должен быть адаптивным (Mobile-First), так как основной трафик детей — это планшеты и смартфоны.
