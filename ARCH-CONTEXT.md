# 🗺️ Контекст Архитектуры проекта: yaroslav-math (v2.0.0)

Этот файл является единственным источником правды (Single Source of Truth) по архитектуре проекта.
Передавайте этот файл ИИ-помощникам (Главный инженер / DeepSeek) при старте новой сессии.

## 🎯 Описание проекта
Статическое веб-приложение на чистом TypeScript и Vite для интерактивного обучения математике (игровой формат). 
Разрабатывается для ребенка по имени Ярослав.

## 🚀 Архитектурные принципы и Стек
1. **Стек:** Vite, чистый TypeScript, HTML5, CSS-модули / Глобальный CSS. Никаких React, Vue, Svelte.
2. **Строгий TypeScript:** Конфигурация `tsconfig.json` запрещает использование типов `any`. Все данные должны быть строго типизированы через интерфейсы (interface) или типы (type).
3. **Монолитное ядро (Shared Core):** Вся общая бизнес-логика (таймеры, работа с памятью, генераторы общих примеров, звуки) пишется строго в `src/core/` и используется играми повторно. Дублирование кода в папках игр запрещено.
4. **Изолированные игры:** Каждая игра живет в своей папке внутри `src/games/` и наследуется от абстрактного класса `BaseGame`.

## 📂 Структура папок (Строгий стандарт)
* `.github/workflows/` — CI/CD пайплайны (автоматический деплой).
* `src/core/` — Логика ядра приложения:
  * `Timer.ts` — Универсальный игровой таймер с колбэками тиков и завершения.
  * `StateManager.ts` — Менеджер очков, рекордов и синхронизации с localStorage.
* `src/components/` — Глобальные UI-компоненты (модальные окна, анимации, салюты).
* `src/games/` — Игры:
  * `base/BaseGame.ts` — Абстрактный класс-шаблон жизненного цикла игры.
  * `game-arithmetic/` — Игра "Быстрый счет" (Сложение/вычитание до 20).
* `src/assets/` — Статические ресурсы (CSS, Audio, Images).

## 🛠️ Жизненный цикл игры (Контракт BaseGame)
Каждая игра ОБЯЗАНА реализовать три метода:
1. `init(): void` — Создает/монтирует DOM-структуру игры в контейнер `#game-container` и вызывает `start()`.
2. `generateTask(): void` — Генерирует математическую задачу и обновляет экран.
3. `checkAnswer(answer: any): boolean` — Сверяет ответ, начисляет очки в `this.score` и запускает следующий шаг.

## 🤖 Правила для Кодера (DeepSeek)
* Пиши функции атомарно (одна функция — одна задача).
* При создании новой игры никогда не создавай заново свойства `score` или логику `setInterval` для таймера — всё это уже встроено в `BaseGame`.
* Локальные стили игры пиши в `style.css` внутри папки этой игры. Не ломай `src/assets/css/global.css`.
